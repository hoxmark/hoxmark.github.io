Hva vi samler inn

Solsti samler ingen personopplysninger.

Posisjonsdata brukes utelukkende lokalt på enheten din for å beregne solposisjon og hente nærliggende kartdata. Posisjonen din sendes aldri til oss eller tredjeparter.

Tredjepartstjenester

  • Apple WeatherKit - brukes til å hente lokalt vær. Apples egne vilkår gjelder: https://developer.apple.com/weatherkit/data-source-attribution/
  • OpenStreetMap / Overpass API - åpne kartdata som hentes via Overpass API. Ingen bruker-ID eller persondata sendes. Lisens: ODbL.
